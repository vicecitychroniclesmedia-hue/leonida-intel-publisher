Leonida Intel Publisher

The private publishing tool behind the Leonida Intel YouTube channel.

Uses YouTube API Services

Leonida Intel Publisher is an internal desktop tool used only by the owner of the Leonida Intel YouTube channel (@InsideLeonidaIntel). It is not offered, sold or distributed to anyone else.

The tool uses the YouTube API Services to:

  • upload videos the channel owner produced to the owner's own channel and schedule when they go public;
  • set each video's title, description, tags, category, audience ("made for kids") and paid-promotion declarations;
  • set the custom thumbnail of each uploaded video;
  • post one comment from the channel owner on the owner's own videos;
  • read the owner's own channel statistics and YouTube Analytics to track channel growth.

It never accesses any other user's account or data.
